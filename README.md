# Daily Tower — 毎日登る、終わりなき塔

戦闘とイベントを進めながら終わりなき塔を登る、ブラウザで遊べるターン制ローグライトRPGです。  
新しい階層・敵・装備・イベントが日々追加されていく設計になっています。

**▶ プレイはこちら： https://daily-tower.pages.dev/**

## 主な特徴

- **純クライアントサイド SPA**: サーバー不要でブラウザ上ですぐにプレイ可能（Cloudflare Pages などの静的ホスティング向け）
- **エンカウント単位の自動保存**: `localStorage` に進行状況を保存し、リロードしても同じ戦闘・イベントから再開可能
- **データ自己修復 & バックアップ**: セーブデータのバリデーション／自己修復に加え、JSON ファイルでのエクスポート／インポートに対応
- **図鑑・実績・聖堂（コスメティック）**: 倒した敵の記録、実績解除、次元跳躍（50層ごとのソフトリセット）による記録アーカイブと見た目カスタマイズ
- **更新の可視化**: 実装済みの最新フロアや領域ごとの進捗、直近追加されたフロアをゲーム内から確認可能

## 技術スタック

- React 19 + TypeScript + Vite 6
- Tailwind CSS v4
- Vitest（ユニットテスト & ヘッドレス・プレイテストシミュレーション）

## 開発・ビルド手順

```bash
# 依存パッケージのインストール
npm ci

# 開発サーバー起動
npm run dev

# テスト実行
npm test

# 本番ビルド（dist/ に出力）
npm run build
```

## セーブデータについて

セーブデータはすべてお使いのブラウザの `localStorage`（スロット1: `DAILY_TOWER_SAVE`、スロット2/3: `DAILY_TOWER_SAVE_SLOT_2` / `_3`）に保存され、外部サーバーには送信されません。  
ブラウザのキャッシュ削除や端末移行に備えて、タイトル画面の「データ管理」から JSON バックアップを保存できます。

## デプロイ・運用（Cloudflare Pages）

- **ビルドコマンド**: `npm run build` / **出力ディレクトリ**: `dist`
- **キャッシュ・セキュリティ設定**: `public/_headers` により、`index.html` は `no-cache`（毎日更新が即反映されるよう再検証）、ハッシュ付き `/assets/*` は長期キャッシュに設定しています。
- **CI**: `.github/workflows/ci.yml` で `main` プッシュ・PR 時にビルドと Vitest を自動実行します。
- **アクセス解析**: Cloudflare Pages ダッシュボードの「Web Analytics」を有効化すると、Cookie 不使用・無料で閲覧状況を計測できます。
